# mini-analysis-numpy-real-dataset-.py
A mini analysis practice by a real dataset of White Wines as a part of my journey to learn numpy principles and fundamental basics of Datasets.


A mini data analysis project using **NumPy** to analyze the Wine Quality dataset.

The goal of this project is to practice working with NumPy arrays and apply concepts.

##  Dataset

This project uses the **Wine Quality** dataset from the UCI Machine Learning Repository.

The dataset contains physicochemical measurements of Portuguese Vinho Verde wines along with a quality score.

For this project, the **white wine dataset** is used.

Dataset source:

https://archive.ics.uci.edu/dataset/186/wine+quality

##  Technologies

- Python
- NumPy
